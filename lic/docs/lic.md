# 📄 lic.md — Спецификация сервиса лицензирования 1С

## 🔍 Назначение сервиса

Сервис `lic` предоставляет **только для чтения** мониторинг лицензий сервера 1С через прямой парсинг файлов `.lic` в каталоге `/var/1C/licenses`. Реализует безопасный доступ к регистрационным номерам, типам лицензий и статистике использования без зависимости от утилиты `ring` (Java) и без рискованных операций активации/деактивации.

## 🌳 Файловая структура проекта

```
/opt/1cv8/scripts/
├── orchestrator.py          # Единая точка входа (ib1c)
├── ib_list.conf             # Статический список ИБ для массовых операций
├── core/                    # Инфраструктурный слой (общий для всех доменов)
│   ├── engine.py            # run_engine() — запуск скриптов от имени usr1cv8
│   ├── utils.py             # machine_to_human(), форматирование размеров
│   └── exceptions.py        # Кастомные исключения (RuntimeError)
│
└── lic/                     # 🪪 Домен: мониторинг лицензий 1С
    ├── engines/             # Слой 0: bash-движки (прямой доступ к ФС)
    │   ├── license_list.sh  # Парсинг .lic → TSV (regnum, filename, type, users)
    │   ├── license_detail.sh# Детализация лицензии через grep/tail
    │   ├── monitor.sh       # Подсчёт клиентских/серверных лицензий + сессий
    │   └── backup.sh        # Копирование .lic в /home/usr1cv8/backups/licenses/
    │
    ├── services/            # Слой 1: бизнес-логика (чистая, без зависимостей от интерфейсов)
    │   ├── __init__.py      # Маркер пакета
    │   └── lic_service.py   # LicenseMonitor — агрегация данных из движков
    │       ├── get_license_list()   → вызов license_list.sh → парсинг TSV
    │       ├── get_license_info()   → вызов license_detail.sh → парсинг key=value
    │       ├── get_monitoring()     → вызов monitor.sh → парсинг key=value
    │       └── create_backup()      → вызов backup.sh → извлечение путей
    │
    └── adapters/cli/        # Слой 2: адаптеры интерфейсов
        ├── __init__.py      # Маркер пакета
        └── lic_adapter.py   # CLI-адаптер (argparse → LicenseMonitor → таблицы)
            ├── Парсинг аргументов (-A, -l, -m, -b)
            ├── Вызов методов LicenseMonitor
            └── Форматирование вывода (ASCII-таблицы с переносом строк)
```

## ⚙️ Алгоритм вызова и зависимости

| Уровень    | Компонент                        | Зависимости                            | Алгоритм вызова                                                                                                                                                                             |
| ---------- | -------------------------------- | -------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| **CLI**    | `lic_adapter.py::main()`         | `argparse`, `LicenseMonitor`           | 1. Парсинг аргументов (`-A`, `-l N`, `-m`, `-b`)<br>2. Создание экземпляра `LicenseMonitor()`<br>3. Вызов соответствующего метода сервиса                                                   |
| **Сервис** | `lic_service.py::LicenseMonitor` | `core.engine.run_engine`, `glob`       | 1. `_run_engine(script, args)` → `core.engine.run_engine(f"lic/engines/{script}", args, user="usr1cv8")`<br>2. Парсинг вывода движка (TSV/key=value)<br>3. Возврат структурированных данных |
| **Движок** | `lic/engines/*.sh`               | `grep`, `awk`, `tail`, права `usr1cv8` | 1. Прямой парсинг `/var/1C/licenses/*.lic`<br>2. Извлечение полей через `grep`/`awk`<br>3. Вывод в машинно-читаемом формате (TSV/key=value)                                                 |

**Критический путь для `ib1c lic -l 8101453530G0`:**

```
orchestrator.py
  → lic_adapter.py::main(['-l', '8101453530G0'])
    → LicenseMonitor().get_license_info('8101453530G0')
      → _run_engine('license_detail.sh', ['8101453530G0'])
        → core.engine.run_engine('lic/engines/license_detail.sh', ['8101453530G0'], user='usr1cv8')
          → bash: grep '8101453530G0' /var/1C/licenses/*.lic → tail -n30 → awk
      → парсинг key=value → dict
    → draw_table() → вывод в терминал
```

## 🧪 Примеры команд

```bash
# Сводка по всем лицензиям (8 блоков)
ib1c lic -A

# Детализация лицензии (с/без суффикса G0)
ib1c lic -l 8101453530G0
ib1c lic -l 8101453530

# Мониторинг использования
ib1c lic -m

# Резервная копия лицензий
ib1c lic -b
```

## ⚠️ Таблица ошибок и обработка

| Ошибка                         | Причина                                           | Обработка в коде                                                                         | Поведение пользователя                                          |
| ------------------------------ | ------------------------------------------------- | ---------------------------------------------------------------------------------------- | --------------------------------------------------------------- |
| `Файл лицензии не найден`      | Отсутствует `/var/1C/licenses/*.lic`              | `license_list.sh`: проверка `[ ! -d "$LICENSES_DIR" ]` → exit 1 с сообщением `error=...` | `lic_adapter.py` ловит `RuntimeError` → вывод в `stderr`        |
| `Нет прав на чтение`           | Пользователь не `usr1cv8` и не в группе `grp1cv8` | Все движки запускаются через `core.engine.run_engine(..., user="usr1cv8")`               | Прозрачно для пользователя — доступ всегда есть                 |
| `Лицензия не найдена`          | Неверный регистрационный номер                    | `license_detail.sh`: `grep -q` → exit 1 → `lic_service.py` возвращает `None`             | `lic_adapter.py` выводит `❌ Лицензия с номером ... не найдена` |
| `Бинарные данные в файле`      | Смешанная кодировка (cp1251 + бинарный префикс)   | `license_detail.sh`: `tail -n30` игнорирует бинарный префикс, `grep` работает с байтами  | Прозрачно — номера всегда находятся в текстовом хвосте          |
| `Синтаксическая ошибка в bash` | Искажение спецсимволов при развёртывании          | Отказ от `set -euo pipefail` в движках, использование `cat > файл <<'EOF'`               | Предотвращено на этапе развёртывания                            |
